# Gazki VSL Landing Page

A high-conversion Video Sales Letter (VSL) landing page for **Gazki Ltd**, designed to help entrepreneurs and companies build international trade deals with a repeatable system.

## 🚀 Tech Stack

- **Framework:** [Vue 3](https://vuejs.org/) (Composition API)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Integration:** [Calendly](https://calendly.com/) for call bookings

## 📦 Project Structure

```text
├── src/
│   ├── components/
│   │   ├── VSLPlayer.vue       # Video player component
│   │   └── CalendlyWidget.vue  # Calendly integration
│   ├── App.vue                 # Main page layout
│   ├── main.ts                 # Entry point
│   └── style.css               # Global styles & Tailwind directives
├── public/                     # Static assets
├── index.html                  # Entry HTML
├── tailwind.config.js          # Tailwind configuration (brand colors)
└── vite.config.ts              # Vite configuration
```

## 🛠️ Development

### Prerequisites
- Node.js (Latest LTS recommended)
- npm

### Installation
```bash
npm install
```

### Local Development
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```

### Deployment to GitHub Pages
```bash
npm run deploy
```

## 🎨 Design System
- **Primary Color:** `#D9AD3D` (Gazki Gold)
- **Secondary Color:** `#1F2C35` (Deep Slate)
- **Typography:** Montserrat (via Tailwind config)
